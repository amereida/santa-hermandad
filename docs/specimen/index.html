Santa Hermandad · fundamentos

Variables de diseño (tokens) del sistema visual: color, tipografía, escala, forma, movimiento. Cada valor proviene de resources/tokens.css y se refleja aquí en vivo.

Para proponer cambios, redefiní variables en el bloque <style id="overrides"> al inicio del documento — la página entera los toma. Anotaciones libres en notes.md.

Las tres capas, y cuál se usa

Las variables están organizadas en tres capas, de la más concreta a la más abstracta. La regla que importa para quien maqueta una plantilla o una página: usar siempre la capa semántica (--sh-paper, --sh-ink, --sh-nova, --sh-link, --sh-ok…). Es la única que voltea entre modo claro y oscuro. Las primitivas son la materia prima y quedan fijas; las de componente son para los controles del skin.

/* tokens.css, capa 1: primitiva, fija */
--sh-papel-50:  #fbf8f3;
--sh-tinta-800: #26231f;

/* capa 2: semántica, una primitiva por modo */
--sh-paper: light-dark(var(--sh-papel-50),
                       var(--sh-tinta-800));

/* capa 3: componente, consume la semántica */
--sh-field-bg: var(--sh-paper);

/* en una plantilla (TemplateStyles): */
.mi-ficha {{ background: var(--sh-paper);
             color: var(--sh-ink); }}      /* ✔ */
.mi-ficha {{ background: var(--sh-papel-50);
             color: #26231f; }}            /* ✘ */

Resumen de capas
CapaCómo se llaman¿Voltean con el modo?¿Quién las usa?
1 · Primitiva (base)--sh-papel-50, --sh-tinta-800, --sh-rojo-500… (familia + peldaño)No: son valores fijos.Sólo tokens.css, para definir la capa 2. Nunca una plantilla.
2 · Semántica (rol)--sh-paper, --sh-ink, --sh-nova, --sh-link, --sh-ok, --sh-warn, --sh-danger, --sh-hairline, --sh-*-wash… y las no cromáticas (--sh-fs-*, --sh-s-*, --sh-radius*)Sí, por light-dark().Plantillas (TemplateStyles), wikitexto, Common.css y el propio skin. Es el contrato: no se renombran ni se eliminan.
3 · Componente--sh-btn-*, --sh-field-*, --sh-on-*, --sh-focus-* y los alias Codex --color-*, --background-color-*Sí, heredado de la capa 2.El skin y OOUI. Una plantilla sólo si está dibujando un control.

Cómo se conmuta el modo. Por defecto la página es clara. data-sh-theme="dark" fuerza oscuro, "light" fuerza claro y "auto" sigue al sistema operativo. Lo único que cambia es color-scheme en la raíz; cada semántica resuelve su rama de light-dark() sola. Nada se redefine por modo, salvo las cuatro variables que cambian de geometría además de color (sombras y grano).

Cómo decidir en qué capa tocar. Tocá la capa más alta que resuelva el problema: reasignar un rol (que --sh-danger apunte a otro rojo) es una línea en la capa 2; cambiar la paleta es la capa 1 y afecta todo; ajustar un control es la capa 3. Las capas 2 y 3 son contrato con las plantillas de la wiki: se pueden añadir variables, no renombrarlas.
